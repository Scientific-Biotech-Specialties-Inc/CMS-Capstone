# Motion sound sources

The motion cues are timed in Remotion using the [Real-SFX workflow](https://clipwing.pro/skills/real-sfx). The files below were released under [CC0](https://creativecommons.org/publicdomain/zero/1.0/). The previews were trimmed to the audible action and converted to mono PCM, with short fades and matched peaks.

| File | Recording |
| --- | --- |
| `whoosh.wav` | [Whoosh](https://freesound.org/people/qubodup/sounds/60013/) by qubodup |
| `pop.wav` | [POP SFX Neutral](https://freesound.org/people/ethernel0/sounds/776016/) by ethernel0 |
| `mouse-click.wav` | [Classic Click](https://freesound.org/people/adh.dreaming/sounds/671105/) by adh.dreaming |
